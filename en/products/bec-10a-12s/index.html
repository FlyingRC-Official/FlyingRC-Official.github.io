FlyingRC 10A 12S BEC Step-down Module

A higher-voltage step-down BEC for converting 2-12S battery voltage into a regulated lower output for onboard electronics.

Best used for

  • Large aircraft or FPV power systems using up to 12S batteries.
  • Builds that need a stronger external BEC than small 5 A modules.
  • Users powering accessories from a high-voltage main battery.

Key features

  • Step-down module for 2-12S LiPo systems.
  • Manual lists capacitor and battery wiring workflow.
  • Designed for higher-current accessory power than small BEC modules.

Setup / wiring notes

  • Confirm output voltage and polarity before connecting flight electronics.
  • Keep high-voltage battery wiring physically separated from signal wiring where possible.

Check before use

  • High-voltage batteries can destroy low-voltage electronics if wired incorrectly.

Key specs

  • 10 A step-down BEC module
  • 6-60 V / 2-12S LiPo input range
  • Designed for higher-current accessory power
