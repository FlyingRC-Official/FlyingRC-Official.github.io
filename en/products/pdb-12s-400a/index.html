FlyingRC 12S 440A FPV Power Distribution Board

A high-current power distribution board for FPV drones. It distributes main battery power to ESCs or other power loads while providing a structured central power node.

Best used for

  • High-voltage FPV builds using up to 12S LiPo.
  • Builds that need a central high-current distribution board.
  • Users planning clean battery-to-ESC power routing.

Key features

  • Manual states 6-60 V DC input / 2-12S LiPo range.
  • Designed for high-current FPV power distribution.
  • Top and bottom PCB renders are available for layout inspection.

Setup / wiring notes

  • Plan battery and ESC wire routing before soldering.
  • Use adequate wire gauge, soldering quality, insulation, and strain relief for high-current paths.

Check before use

  • High-current power distribution failures can be destructive; inspect every solder joint before power-up.

Key specs

  • High-current FPV power distribution board
  • 6-60 V / 2-12S LiPo input range
  • 4 x 80 A continuous / 110 A peak ESC outputs; current sensor range up to 440 A
