FlyingRC L4 CAN RCGPS Adapter CAN Serial and PWM Expansion Board

A CAN bus adapter and serial/PWM expansion board. It lets compatible flight controllers add remote serial/PWM-style peripheral connections through an AP_Periph-style CAN node.

Best used for

  • ArduPilot/CAN builds needing distributed peripheral wiring.
  • Flight controllers with CAN support such as MATEK H7 series and FlyingRC H7Wlite family according to the manual.
  • Users who want to move GPS/RC/PWM-related wiring away from the main controller.

Key features

  • Runs open-source AP_Periph firmware.
  • Uses GH1.25 connectors according to the manual.
  • Designed for CAN bus compatible flight-controller ecosystems.

Setup / wiring notes

  • Wire CAN_H/CAN_L and power correctly, then configure AP_Periph/CAN parameters in the flight controller.
  • Check connector orientation before plugging in serial/PWM peripherals.

Check before use

  • CAN devices require correct bus wiring and termination strategy.

Key specs
