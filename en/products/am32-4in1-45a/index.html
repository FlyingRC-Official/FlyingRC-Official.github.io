FlyingRC 4IN1 45A ESC FPV ESC

A 45 A four-in-one AM32 ESC for FPV drones, intended to drive four brushless motors from one compact board.

Buy on Taobao Email sales WhatsApp support GitHub

Best used for

  • FPV builds that need a lighter current class than the 75 A ESC.
  • AM32 firmware users who want configurable motor behavior.
  • Builds where a single 4-in-1 ESC simplifies wiring.

Key features

  • Pre-flashed with AM32 firmware.
  • Supports DSHOT150/300/600, OneShot, PWM and other control signal inputs.
  • Manual includes firmware flashing and parameter setting workflow.

Setup / wiring notes

  • Remove propellers before ESC parameter tuning or firmware flashing.
  • Power the ESC with a LiPo battery when tuning/flashing, following the ESC manual.
  • Use the offline AM32 parameter tuning workflow; the manuals warn against web-based firmware flashing.

Check before use

  • Incorrect firmware flashing can damage the ESC MCU; use the manual workflow.

Key specs

  • AM32 4-in-1 FPV ESC
  • 45 A per channel class
  • Supports DShot150/300/600, OneShot, and PWM protocols
