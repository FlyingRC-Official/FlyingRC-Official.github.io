FlyingRC AM32 Dual ESC 40A Two-in-one ESC

A two-in-one AM32 ESC that drives two brushless motors from one compact board. It is especially useful for twin-motor fixed-wing aircraft or compact dual-motor builds.

Best used for

  • Twin-motor fixed-wing aircraft.
  • Dual-motor robotics or vehicle builds.
  • Builds that want fewer separate ESC boards and cleaner wiring.

Key features

  • Pre-flashed with AM32 firmware.
  • Dual-stage LDO power supply for gate drivers and MCUs.
  • Supports wide 2-6S input range according to the manual.
  • Sine-wave startup and Stall Protection can improve low-speed torque.

Setup / wiring notes

  • Remove propellers before ESC parameter tuning or firmware flashing.
  • Power the ESC with a LiPo battery when tuning/flashing, following the ESC manual.
  • Use the offline AM32 parameter tuning workflow; the manuals warn against web-based firmware flashing.

Check before use

  • Incorrect firmware flashing can damage the ESC MCU; use the manual workflow.

Key specs

  • AM32 two-in-one ESC
  • 40 A dual-motor class
  • 2-6S LiPo input range
