FlyingRC AM32 ESC Configurator Tool

A USB parameter programmer for AM32 ESCs. It bridges the computer tuning software to an ESC signal wire so users can read parameters, change settings, and flash firmware.

Programming toolESCAM32Offline flashingUSBCH340 driverNo web flashing
Buy on Taobao Email sales WhatsApp support GitHub

Best used for

  • Users tuning AM32 ESCs without routing through a flight controller.
  • Firmware update and parameter adjustment workbench use.
  • Troubleshooting ESC settings before installing into an aircraft.

Key features

  • Connects to the computer by USB and to the ESC signal wire.
  • Manual documents M1 port selection, parameter reading, writing, and firmware flashing workflow.
  • Supports AM32 ESC tuning use cases.

Setup / wiring notes

  • Connect USB first, then connect the programmer signal wire to the ESC signal wire as shown in the diagram.
  • Power the ESC appropriately when tuning or flashing according to the ESC manual.
  • After flashing across multiple versions, send default settings if the manual workflow calls for it.

Check before use

  • Web flashing has damaged ESC MCUs according to the manual; use the offline workflow.

Key specs

  • USB programmer for AM32 ESCs
  • Connects computer tuning software to the ESC signal wire
  • Offline firmware flashing workflow recommended
