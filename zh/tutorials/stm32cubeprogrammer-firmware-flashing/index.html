使用 STM32CubeProgrammer 刷写固件

使用 ST 官方 STM32CubeProgrammer，通过 STM32 USB Bootloader / DFU 接口写入 FlyingRC 的 .hex 固件文件。

适用场景

适用于需要从本地文件恢复、替换或升级 STM32 飞控固件的 FlyingRC 用户。

开始前准备

  • FlyingRC STM32 板卡，以及下载页中与该板卡匹配的固件文件。
  • 电脑已安装 ST STM32CubeProgrammer。
  • 一根确认可传输数据的 USB 线。仅充电线无法识别 Bootloader。
  • 拆除螺旋桨，且除非产品说明书明确要求，否则不要接外部电源。

安全检查

  • 刷写前必须确认固件目标与板卡型号、硬件版本一致。目标错误可能导致板卡无法正常启动。
  • 如果产品说明书中的 BOOT / DFU 进入方式与本通用流程不同，以对应产品说明书为准。
  • 固件恢复测试期间不要连接电机、螺旋桨或带电负载线。

操作步骤

  1. 下载正确固件

    打开 FlyingRC 下载页，选择准确的产品型号，下载与页面中固件目标和硬件版本一致的 .hex 固件。如有校验文件，请一并保留。

  2. 安全准备板卡

    拆除螺旋桨，断开电池电源，拔掉非必要外设。除非产品说明书另有要求，本步骤只使用 USB。

  3. 进入 STM32 Bootloader / DFU 模式

    按照产品说明书按住 BOOT 按键或短接 BOOT 焊盘，再插入 USB。电脑应识别到 STM32 Bootloader / DFU 设备。

  4. 在 STM32CubeProgrammer 中连接

    打开 STM32CubeProgrammer，选择 USB 连接方式，选中识别到的 DFU 设备，然后点击 Connect。如果没有 USB 设备，重新进入 Bootloader 模式，并更换 USB 线或接口重试。

  5. 载入并写入 .hex 文件

    进入 Erasing & Programming 页面，选择下载好的 .hex 文件，保持写入后校验开启，然后开始刷写。STM32CubeProgrammer 提示成功前不要拔掉 USB。

  6. 重启并确认固件正常启动

    在 STM32CubeProgrammer 中断开连接，拔掉 USB，再不按 BOOT 正常重新插入。打开对应配置器或地面站，确认固件可以正常连接。

故障排查

STM32CubeProgrammer 没有显示 USB 设备

更换可传输数据的 USB 线，换 USB 接口，先按住 BOOT 再插 USB，并检查产品说明书是否有特定的 Bootloader 进入方式。

开始写入后失败

重新进入 DFU 模式连接，保持校验开启，避免使用 USB 集线器，并确认文件是完整的 FlyingRC .hex 固件，而不是压缩包。

板卡仍然启动旧固件

确认写入流程已成功完成，然后在不按 BOOT 的情况下重新上电。如果仍异常，重新选择正确的 .hex 文件再刷写一次。

刷写后配置器无法连接

使用与固件体系匹配的配置器，确认 USB 串口设备是否出现，并再次核对固件目标是否与板卡一致。
