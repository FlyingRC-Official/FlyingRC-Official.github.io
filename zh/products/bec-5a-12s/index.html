BEC 降压模块最新

FlyingRC 12S 5A BEC V1 降压模块

一款适用于 2-12S 装机的紧凑型高压 BEC，默认输出 5V，可跳线选择 12V。

BEC / 降压模块固定翼2-12S LiPo可选 BEC 输出高压输入
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

主要功能

  • 支持 6-60V 输入。
  • 默认 5V 输出；跳线可选 12V。
  • 随附 35V 220uF 电解电容。

设置 / 接线注意

  • VIN 接电池，VO 接负载；电容安装在负载侧。

使用前检查

  • 连接敏感设备前，先确认输出跳线选择。

关键参数

  • 输入 6-60V，支持 2-12S LiPo
  • 默认 5V 输出；跳线可选 12V
  • 6S 输入时 5V 持续 5A；12S 输入时 5V 持续 3.5A
  • 尺寸 30.01 x 17.82 x 5.52 mm；不含电容重 5.4g
