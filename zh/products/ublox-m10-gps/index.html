传感器与 GPS

FlyingRC U-Blox M10 GPS

一款 U-Blox M10 GPS 模块，用于为飞控、机器人或导航系统提供位置信息。

导航 / 传感器固定翼穿越机 / 多旋翼GPS / GNSSU-Blox M10ArduPilotBetaflightINAV
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要悬停、返航、航点导航或日志定位等 GPS 辅助模式的飞机。
  • 在说明书系列中的 18 x 18 mm、20 x 20 mm、28 x 28 mm GPS 规格之间选择的用户。
  • 需要 GNSS 数据的 Betaflight/INAV/ArduPilot 用户。

主要功能

  • 说明书包含多种尺寸型号介绍。
  • 包含 BF 和 INAV 等固件设置章节。
  • 作为导航传感器使用，而不是供电或控制板。

设置 / 接线注意

  • 安装时保证良好天空视野。
  • 按所用飞控配置 GPS 协议和串口。

使用前检查

  • 不要假设所有 M10 版本的接口方向和尺寸完全相同。

关键参数

  • U-Blox M10 GPS
  • 导航模块
  • 包含产品渲染图
