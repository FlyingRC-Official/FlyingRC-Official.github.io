FlyingRC ELRS 2.4G 分集接收机

一款 2.4G ELRS 分集接收机。它从 ExpressLRS 遥控发射端接收控制指令并发送给飞控，通过分集接收提升链路可靠性。

接收机穿越机 / 多旋翼ExpressLRS真分集UART / 串口
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 使用 ExpressLRS 2.4G 的穿越机或固定翼。
  • 希望使用分集接收机而不是基础单天线接收机的玩家。
  • 需要确认接收机固件兼容性的装机。

主要功能

  • 说明书包含固件刷写流程。
  • 说明书记录出厂固件版本为 3.5.5。
  • 说明书建议发射模块固件升级到 3.x 或更高以确保兼容。

设置 / 接线注意

  • 飞行前确认接收机和发射模块固件版本匹配。
  • 天线尽量远离碳板、电池和大电流线。

使用前检查

  • 遥控链路可靠性取决于天线安装和固件兼容性。

关键参数

  • ELRS 2.4G 接收机
  • 分集接收机定位
