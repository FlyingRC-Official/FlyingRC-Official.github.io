FlyingRC RM3100 SPI 罗盘模块

一款可远离磁干扰源安装的三轴罗盘模块，用于飞行器、机器人和导航项目的航向测量。

导航 / 传感器RM3100 罗盘SPI固定翼外置安装
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

主要功能

  • 采用 PNI RM3100 磁传感器组和 MagI2C 控制器。
  • 提供 SPI 时钟、MISO、MOSI、片选和数据就绪信号。
  • 安装后必须完成全姿态校准。

设置 / 接线注意

  • 使用 3.3V 供电，并遵循 8Pin SPI 接线表。
  • 模块应远离动力线、电机和其他磁干扰源安装。

使用前检查

  • 请勿使用 5V 为模块供电。

关键参数

  • PNI RM3100 三轴地磁传感器
  • 尺寸 12.70 x 12.70 x 7.42 mm；重量 0.53g
  • 推荐 3.3V 供电；工作范围 2.0-3.6V
  • 8Pin SPI：VCC、双 GND、DRDY、CLK、MISO、MOSI、SSN
