电调

FlyingRC AM32 ESC 75A V2.5 单体金封电调

一块 75 A 单路 AM32 电调，用于驱动一个大电流无刷电机。适合每个电机独立电调或单个大功率电机的场景。

固定翼机器人 / 车辆电调单体电调AM322-6S LiPo板载 BEC大电流装机
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 大电流固定翼或车辆电机。
  • 需要每个电机独立电调，而不是四合一电调的用户。
  • 需要配置刹车、启动和保护行为的 AM32 场景。

主要功能

  • AM32 固件，支持正弦启动和堵转保护。
  • 正确配置后可提供较强低速扭矩。
  • 说明书记录固件和参数更新流程。

设置 / 接线注意

  • 电调调参或刷固件前必须拆桨。
  • 调参/刷写时按电调说明书使用 LiPo 电池给电调供电。
  • 使用离线 AM32 调参流程；说明书警告不要用网页版流程刷固件。

使用前检查

  • 错误刷写固件可能损坏电调 MCU，应按说明书流程操作。

关键参数

  • AM32 单体电调
  • 75A 级别
  • V2.5 上架资料
