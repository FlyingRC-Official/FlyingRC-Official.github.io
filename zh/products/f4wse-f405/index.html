FlyingRC F4WSE F405 主控固定翼飞控

面向固定翼的 F405 自动驾驶飞控，适合 ArduPilot/INAV 类飞机装机。它连接接收机、传感器、舵机和电调，负责姿态稳定、导航、数传和飞行模式控制。

固定翼飞控STM32F405ArduPilotINAVUART / 串口需核对串口映射
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要成熟 F405 级飞控的固定翼飞机。
  • 想使用固定翼固件但不需要更大 H7 板的用户。
  • 重视接线图和 ArduPilot 串口映射的装机。

主要功能

  • F405 固定翼飞控系列。
  • 说明书包含技术参数、产品特点、固件使用和接线章节。
  • 围绕开源飞控固件工作流设计。

设置 / 接线注意

  • 从说明书推荐的固定翼固件开始，先验证接收机、GPS、数传、PWM 输出和供电，再进行动力测试。

使用前检查

  • ArduPilot 的 SERIAL 编号不一定等于板子丝印上的 UART/USART 名称。

关键参数

  • F405 主控
  • 固定翼飞控布局
  • 提供 Type-C 渲染素材
