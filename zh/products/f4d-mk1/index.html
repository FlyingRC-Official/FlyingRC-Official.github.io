飞控

FlyingRC F4D MK1 F405 主控穿越机飞控

一块紧凑型 F405 穿越机飞控。默认运行 Betaflight，负责连接接收机、电调信号线、图传/相机、OSD、蜂鸣器、LED 和其他穿越机外设。

穿越机 / 多旋翼飞控STM32F405BetaflightDJI O4DJI O4 供电2-6S LiPo图传接线
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要 20 x 20 mm 或 30.5 x 30.5 mm 孔距灵活安装的穿越机。
  • 使用 DJI O4 或类似高清图传接线的数字图传装机。
  • 希望默认使用 BF，同时保留 AP/INAV 可选项的用户。

主要功能

  • STM32F405RGT6 主控。
  • 支持 AP、Betaflight、INAV；出厂默认 Betaflight。
  • 板载 9 V BEC 可给图传/相机供电，并可通过 PINIO1/User1 控制。
  • 接线图适用于 BF、AP、INAV 使用流程。

设置 / 接线注意

  • 刷固件或台架测试前必须拆桨。
  • 如果使用出厂固件，优先参考 BF 接线示例。
  • 使用 ArduPilot 时要核对 SERIAL 映射，因为 SERIAL 编号不与 UART 丝印一一对应。

使用前检查

  • 图传供电稳定性与电池电压有关，长时间台架测试前要确认 BEC 电压条件。

关键参数
