FlyingRC H7Wlite V2 H743 主控固定翼飞控

H7Wlite V2 硬件版本采用双 BMI270 IMU、SPA06-003 气压计和内置 QMC5883P 罗盘。ArduPilot 与 INAV 保留旧版 ICM 支持；Betaflight 仅适用于 BMI270。

固定翼飞控STM32H743ArduPilotINAVBetaflightCANPWM 输出
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

关键参数

  • STM32H743 固定翼飞控
  • 双 BMI270 IMU；ArduPilot 与 INAV 仍支持旧版 ICM 替代器件
  • I2C2 上的 SPA06-003 气压计与内置 QMC5883P 罗盘
  • 12 路 PWM、SDIO 日志、模拟 OSD、CAN 与 7 路 UART
