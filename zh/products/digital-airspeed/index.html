FlyingRC 无空速管数字空速计

一款无空速管数字空速计，用于在不安装外置空速管的情况下，为固定翼固件提供有用的空速信息。

导航 / 传感器固定翼无空速管空速ArduPilot紧凑装机
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 不方便安装空速管或空速管容易损坏的固定翼。
  • 希望使用空速相关飞行功能的 ArduPilot 用户。
  • 使用 ArduPilot 自动热气流盘旋功能的实验装机。

主要功能

  • 说明书标注支持 ArduPilot 固件的自动热气流盘旋。
  • 定位为传感器配件，不是主飞控。
  • 说明书包含 ArduPilot 设置/配置流程。

设置 / 接线注意

  • 在依赖空速相关模式前，先在 ArduPilot 中完成配置。
  • 先台架检查读数，再在安全飞行条件下验证。

使用前检查

  • 应作为飞行辅助传感器使用，在关键自主功能前必须验证行为。

关键参数

  • 数字空速传感器
  • 无空速管定位
  • 固定翼传感器配件
