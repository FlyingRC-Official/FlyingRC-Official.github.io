电调

FlyingRC 4IN1 75A ESC 四合一穿越机金封电调

四合一穿越机电调。它接收一个电池输入，并根据飞控油门信号分别驱动四个无刷电机。

穿越机 / 多旋翼电调四合一电调AM32大电流装机3-7S LiPo30.5mm M3 飞塔孔
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要 75A x4 电调的大电流穿越机。
  • 重视散热和电流余量的 5 寸或更大穿越机。
  • 希望使用可配置 AM32 开源电调固件的用户。

主要功能

  • QF32F4AK8U7 32 位 MCU，集成 ID6288 栅极驱动。
  • Infineon IRF7480 金封 MOSFET。
  • 10 层 2 oz PCB，并使用铜条辅助过流。
  • 出厂预刷 AM32 固件。

设置 / 接线注意

  • 电调调参或刷固件前必须拆桨。
  • 调参/刷写时按电调说明书使用 LiPo 电池给电调供电。
  • 使用离线 AM32 调参流程；说明书警告不要用网页版流程刷固件。

使用前检查

  • 错误刷写固件可能损坏电调 MCU，应按说明书流程操作。

关键参数

  • 四合一穿越机电调
  • 75A 级别
