FlyingRC L4 CAN RCGPS Adapter CAN 总线串口 & PWM 扩展板

一块 CAN 总线串口/PWM 扩展板。它让兼容飞控通过 AP_Periph 类 CAN 节点扩展远端串口和 PWM 外设连接。

导航 / 传感器固定翼CANAP_PeriphSTM32L431UART / 串口PWM 输出CAN 总线接线
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要分布式外设接线的 ArduPilot/CAN 装机。
  • 说明书中提到的 MATEK H7 系列和 FlyingRC H7Wlite 等支持 CAN 的飞控。
  • 希望把 GPS/RC/PWM 类接线从主飞控移开的用户。

主要功能

  • 运行开源 AP_Periph 固件。
  • 说明书标注使用 GH1.25 接口。
  • 面向支持 CAN 总线的飞控生态。

设置 / 接线注意

  • 正确连接 CAN_H/CAN_L 和供电后，在飞控中配置 AP_Periph/CAN 参数。
  • 插入串口/PWM 外设前确认接口方向。

使用前检查

  • CAN 设备需要正确总线接线和终端策略。

关键参数

  • CAN 总线适配器
  • 串口与 PWM 扩展
  • 外设集成板
