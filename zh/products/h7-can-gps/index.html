FlyingRC H7 CAN GPS

FlyingRC CAN/GPS 类导航配件资料页。它为飞控提供位置信息，使自动模式、返航、导航和日志记录能够工作。

导航 / 传感器固定翼GPS / GNSSCANArduPilotCAN 总线接线
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 需要外置 GPS 的 ArduPilot 类装机。
  • 正在规划 CAN/GPS 接线的固定翼或多旋翼用户。
  • 需要导航模块，而不只是手动飞行的用户。

主要功能

  • 产品资料标识为 H7 CAN GPS。
  • 需搭配支持对应 GPS/CAN 工作流的飞控固件使用。

设置 / 接线注意

  • GPS 应安装在视野开阔、远离大电流噪声源的位置。
  • 在固件中确认 CAN/GPS 协议和波特率/参数。

使用前检查

  • GPS 效果取决于天线位置和固件配置。
