FlyingRC AM32 电调调参器

一款 AM32 电调 USB 调参器。它把电脑调参软件和电调信号线连接起来，用于读取参数、修改设置和刷写固件。

调参 / 刷写工具电调AM32离线刷写USBCH340 驱动不要网页刷写
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 希望不经过飞控、直接调试 AM32 电调的用户。
  • 固件更新和参数调整台架使用。
  • 装机前排查电调参数问题。

主要功能

  • 通过 USB 连接电脑，并连接电调信号线。
  • 说明书记录 M1 端口选择、参数读取/写入和固件刷写流程。
  • 支持 AM32 电调调参场景。

设置 / 接线注意

  • 先连接 USB，再按图连接调参器信号线和电调信号线。
  • 调参或刷固件时按电调说明书为电调正确供电。
  • 跨多个版本刷固件后，按说明书流程恢复默认参数。

使用前检查

  • 说明书记录网页版刷写可能损坏电调 MCU，应使用离线流程。
