FlyingRC I2C 数字空速计

面向使用 ArduPilot 空速工作流的固定翼飞机的最新一代 I2C 一体式空速计。

导航 / 传感器固定翼I2CArduPilot紧凑装机
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

主要功能

  • MS4525D 兼容数字传感器，空速计与空速管一体化。
  • 每只产品出货前均进行零漂校准。
  • 附送硅胶端子线和塑料安装螺丝。

设置 / 接线注意

  • ArduPilot 中设置 ARSPD_TYPE = 1，并在完成基础试飞后按说明书进行校准。
  • 仅在校准飞行期间开启 ARSPD_AUTOCAL，正常使用时应关闭。

使用前检查

  • 本产品为当前型号；旧款无空速管数字空速计保留为 EOL 参考资料。

关键参数

  • MS4525D 兼容数字空速传感器，I2C 接口
  • 尺寸 25 x 15 x 5 mm；重量 2.8g
  • 采样率 512Hz，刷新率 8Hz
  • 支持温度补偿；压力测量精度 0.5Pa RMS
