FlyingRC AM32 Mini ESC 40A V1 单体电调

一块紧凑型单路 AM32 电调，用于驱动一个无刷电机，适合单发固定翼、小型车辆或需要分开放置电调的装机。

固定翼机器人 / 车辆电调单体电调AM322-6S LiPo紧凑装机
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 单发固定翼飞机。
  • 需要 AM32 低速特性的小型车、攀爬车和紧凑机器人。
  • 希望每个电机独立电调而不是四合一电调的装机。

主要功能

  • 出厂预刷 AM32 固件。
  • 开启正弦启动和堵转保护后，可提供较强低速扭矩。
  • 说明书包含离线固件刷新和参数设置流程。

设置 / 接线注意

  • 电调调参或刷固件前必须拆桨。
  • 调参/刷写时按电调说明书使用 LiPo 电池给电调供电。
  • 使用离线 AM32 调参流程；说明书警告不要用网页版流程刷固件。

使用前检查

  • 错误刷写固件可能损坏电调 MCU，应按说明书流程操作。

关键参数

  • AM32 固件系列
  • 40A 单体电调
  • Mini 紧凑尺寸
