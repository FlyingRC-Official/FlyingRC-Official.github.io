电调最新

FlyingRC AM32 Dual ESC 40A 二合一电调

一块二合一 AM32 电调，用一块板驱动两个无刷电机，特别适合双发固定翼或紧凑双电机装机。

固定翼机器人 / 车辆电调二合一电调AM322-6S LiPo紧凑装机
去淘宝购买 邮件咨询 WhatsApp 技术支持 GitHub

适合场景

  • 双发固定翼飞机。
  • 双电机机器人或车辆装机。
  • 希望减少独立电调数量、简化走线的装机。

主要功能

  • 出厂预刷 AM32 固件。
  • 栅极驱动和 MCU 使用双级 LDO 供电。
  • 说明书标注支持 2-6S 宽输入范围。
  • 正弦启动和堵转保护可改善低速扭矩。

设置 / 接线注意

  • 电调调参或刷固件前必须拆桨。
  • 调参/刷写时按电调说明书使用 LiPo 电池给电调供电。
  • 使用离线 AM32 调参流程；说明书警告不要用网页版流程刷固件。

使用前检查

  • 错误刷写固件可能损坏电调 MCU，应按说明书流程操作。

关键参数

  • 二合一电调布局
  • 40A 级别
  • AM32 固件系列
